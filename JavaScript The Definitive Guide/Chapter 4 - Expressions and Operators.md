This chapter documents JavaScript **expressions** and the **operator** with which many of those expressions are built. An *expression* is a phrase of JavaScript that can be *evaluated* to produce a value. A constant embedded literally in our program is a very simple kind of expression.

A variable name is also a simple expression that evaluates to whatever value has been assigned to that variable. Complex expressions are built from simpler expressions. 

Uma expressão de acesso a uma matriz, por exemplo, consiste em uma expressão que é avaliada como uma matriz seguida de um colchete aberto, uma expressão que é avaliada como um número inteiro e um colchete fechado. Essa expressão nova e mais complexa é avaliada como o valor armazenado no índice especificado da matriz especificada. Da mesma forma, uma expressão de invocação de função consiste em uma expressão que é avaliada como um objeto de função e zero ou mais expressões adicionais que são usadas como argumento da função. 

A maneira mais comum de criar uma expressão complexa a partir de expressões mais simples é com um operador. Um operador combina os valores de seus operandos (geralmente dois deles) de alguma forma e os avalia em um novo valor. O operador de multiplicação * é um exemplo simples. A expressão x * y é avaliada como o produto dos valores das expressões x e y. Para simplificar, às vezes dizemos que um operador retorna um valor em vez de "avalia para" um valor.
